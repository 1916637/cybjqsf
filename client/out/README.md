# 客户端产出目录

本目录为**运行时输出**，交付时为空。接手者按 `docs/00_` 手册第 5 步执行后，会在这里得到：

| 文件 | 由谁生成 |
|---|---|
| `创游编辑器_私服版_未签名.apk` | `client/tools/build_revived_apk.py` |
| `创游编辑器_私服版_aligned.apk` | `sign_apk.sh` 中间产物 |
| `创游编辑器_私服版_已签名.apk` | `sign_apk.sh` ← **装进手机的就是这个** |
| `revive.jks` | `sign_apk.sh` 现场生成的签名密钥 |

> 制作本包时已用测试 IP 完整跑通「补丁 → 校验 → 签名 → apksigner 验证」全链路，
> 验证通过后已把产物清空，避免把测试地址编译进交付包。**本目录不含任何预置 IP。**
